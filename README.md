# JxLiu个人网站

基于 [Minimal Mistakes](https://github.com/mmistakes/minimal-mistakes) Jekyll 主题搭建的个人展示网站。

## 主要修改

- 替换导航菜单为个人 5 页结构
- 配置个人信息与作者侧边栏
- 新增 About、Skills、Projects、Contact 页面（占位内容）

## GitHub Pages

https://JxLiu006.github.io

## 本地预览

`
gem install bundler
bundle install
bundle exec jekyll serve
`

浏览器打开 http://localhost:4000
