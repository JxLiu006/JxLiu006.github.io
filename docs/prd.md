**版本：** v1.0
**日期：** 2026-07-24
**技术栈：** Jekyll + Minimal Mistakes 主题
**模版仓库：** https://github.com/mmistakes/minimal-mistakes
**目标部署：** https://JxLiu006.github.io（GitHub Pages）

## 1. 目标访问者

- 同学（浏览作品、了解学习方向，方便课内外交流）
- 教师（评估项目完整性与技术理解）
- 未来项目伙伴（判断合作方向与技术兴趣是否匹配）

### 他们最先寻找什么信息

- 我是谁、在学什么方向
- 掌握哪些技术能力
- 有没有实际项目可看
- 如何联系我

## 2. 希望访问者记住什么

JxLiu —— 金融科技方向学习者，能用 Agent 驱动的技术方案解决真实场景下的效率与决策问题。

## 3. 本期必须包含的内容

- 个人简介（一段话定位 + 详细背景）
- 能力与兴趣（技术栈列表 + 方向列表）
- 项目方向入口（框架，内容后续填充）
- 公开联系方式（邮箱、GitHub、LinkedIn、微信可选）
- 隐私保护（所有页面不暴露身份证号、住址、私人手机号、课程邀请码、API Key、不适合公开的照片）

## 4. 本期明确不做什么（Out of Scope）

- 不加入用户登录/注册系统
- 不加入数据库或任何后端存储
- 不加入支付功能
- 不加入复杂后台管理系统
- 不采集访客隐私（无 Cookie 横幅、默认不启用分析追踪）
- 不加入评论系统
- 不主动配置 SEO（主题自带的基础 SEO 保留）
- 不配置自定义域名（先用 GitHub Pages 默认域名）
- 不加入内容管理系统
- 不制作自定义 404 页面
- 不加入英文版本（单语言中文）

## 5. 怎样判断网站完成（验收标准）

以下六项为基础验收门槛。任一缺失，作业会被标记为"需要修正"。

### 5.1 页面可访问

- 所有 5 个页面（首页、About、Skills & Interests、Projects、Contact）均可在浏览器打开，无 404
- 导航栏各链接跳转到正确页面
- 侧边栏社交图标链接可点击（即使目标页面尚不存在或为占位）
- GitHub Pages 部署后可被公开访问

### 5.2 内容真实

- 占位文案为有意义的指示性文本（"待补充" / "更多项目即将更新"），不使用 lorem ipsum
- 页面标题、导航标签、描述与实际内容一致
- 网站定位、隐私边界由本人确认

### 5.3 移动端可读

- 在 375px 宽视口下，所有页面无水平滚动、无文字溢出、无元素重叠
- 导航栏在窄屏下折叠为汉堡菜单且可操作

### 5.4 隐私合规

- 任何页面不出现私人手机号、住址、身份证号、课程邀请码、API Key
- About 页使用 logo / placeholder 代替真实照片
- 仓库不包含密钥和私人数据（由 .gitignore 兜底）

### 5.5 链接有效

- 所有内部链接（导航、页面间跳转）返回 200
- 所有外部链接（社交图标等）指向正确的目标 URL
- 无断链或指向不存在页面的链接

### 5.6 过程材料完整

- docs/prd.md — 本文件
- docs/design.md — 设计说明
- docs/checklist.md — 可验证的验收清单
- report/final-report.md — 最终报告
- screenshots/ — 至少 4 张证据截图（桌面端首页、手机端首页、GitHub Pages 部署状态、完成后的 Checklist）
- README.md — 项目说明
- 至少 3 次有意义 Git Commit

## 6. 哪些信息不能公开

- 身份证号
- 家庭住址
- 私人手机号
- 课程邀请码
- 任何 API Key 或 Token
- 不适合公开的个人照片
